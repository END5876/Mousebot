連線到 Discord Bot

需要 Bot 主機上跑著對應的 webui/server.js。 這個頁面若是由該伺服器提供（同一個網址開出來的），下方會自動嘗試連線； 若是你直接用瀏覽器開這個 .html 檔案，請先手動填寫 API 位址。

小技巧：連線＋選好伺服器／行程後按「複製一鍵連線書籤網址」，存成瀏覽器書籤或加到手機主畫面。之後點一下就會自動帶入金鑰並直接載入行程。

「儲存回 Bot」會覆蓋伺服器上該行程的資料；如果偵測到伺服器上的版本跟你最後一次同步的不一樣，會先跳出提醒再決定要不要覆蓋。

已連線 Bot 時，資料會直接同步到雲端；以下是離線編輯或備援用的本機方式，平常不一定會用到。
