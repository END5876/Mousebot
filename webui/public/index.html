連線到 Discord Bot

需要 Bot 主機上跑著對應的 webui/server.js（見部署說明）。 這個頁面若是由該伺服器提供（同一個網址開出來的），下方會自動嘗試連線； 若是你直接用瀏覽器開這個 .html 檔案，請先手動填寫 API 位址。

小技巧：連線＋選好伺服器／行程後按「複製一鍵連線書籤網址」，把網址存成瀏覽器書籤。之後每次點書籤就會自動帶入金鑰並直接載入行程，不用再手動輸入。

「儲存回 Bot」會直接覆蓋伺服器上該行程的資料，請先載入最新版本再編輯，避免蓋掉別人剛記的帳。
